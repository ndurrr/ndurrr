The Nest widget

Hilal's one quest on your home screen and lock screen. Tap it and you're in the Nest.

  1. Get Scriptable from the App Store.Free. It's what draws the widget.
  2. Tap the button below to copy the Nest script.
  3. Open Scriptable, tap +, paste, and name it Nest.Tap ▶ once to see it. You only paste it once, it updates itself.
  4. Long-press your home screen, tap +, pick Scriptable, add the medium size. Long-press it, Edit Widget, set Script to Nest.Same for the lock screen: Customise, add Scriptable, pick Nest.
// The Nest widget. Paste this into a new Scriptable script called "Nest".
// It fetches the latest widget code each time, so it never needs pasting again.
const URL = "https://raw.githubusercontent.com/ndurrr/ndurrr/refs/heads/claude/project-thread-46cnd6/nest/widget.js";
const fm = FileManager.local();
const path = fm.joinPath(fm.documentsDirectory(), "nest-widget-core.js");
try { const s = await new Request(URL).loadString(); if (s.includes("NEST_WIDGET")) fm.writeString(path, s); } catch (e) {}
await importModule(path).run();
